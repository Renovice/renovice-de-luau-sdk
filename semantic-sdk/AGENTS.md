# RENOVICE Semantic SDK instructions

The Semantic SDK joins existing evidence; it does not invent new Warframe API
or native facts.

1. Every generated fact must retain its source file, evidence identifiers, and
   confidence/status boundary.
2. Exact native claims remain keyed to the registered executable build.
3. Conflicting owners, argument shapes, or result types remain separate or
   unresolved. Never merge them by plausibility.
4. Generated output must be deterministic and validated before publication.
5. Unknown hashes, receiver types, fields, and native links remain explicit.
6. Treat compiler warnings as errors.
7. Record positive and negative results under `RESEARCH/`.
